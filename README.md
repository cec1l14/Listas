# 🐍 Exercícios de Programação em Python

Este repositório contém as soluções das listas de exercícios de **Introdução à Programação**, desenvolvidas inteiramente na linguagem **Python**.

---

## 🗺️ Conteúdo das Listas

Below está o mapa de tópicos abordados em cada uma das listas de exercícios:

* **📌 Lista 02 | Conceitos Iniciais + Estruturas Condicionais**
  * Entrada e saída de dados, operadores aritméticos/lógicos e controle de fluxo simples (`if`, `elif`, `else`).

* **📌 Lista 04 | Estrutura de Repetição: `while`**
  * Laços de repetição indeterminados, validação de dados, contadores, acumuladores e flags de parada.

* **📌 Lista 06 | Estrutura de Repetição: `for`**
  * Laços de repetição determinados, iteração com `range()`, acumuladores e sequências.

* **📌 Lista 07 | Estruturas de Dados**
  * Manipulação e operações com **Listas** (`list`), **Tuplas** (`tuple`) e **Dicionários** (`dict`).

* **📌 Lista 08 | Funções e Strings**
  * Modularização de código (funções com/sem retorno e parâmetros) e manipulação/fatiamento de textos (`strings`).
